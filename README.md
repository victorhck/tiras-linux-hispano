## La Tira de Linux Hispano

Repositorio que contiene una copia de las imágenes de La Tira de Linux Hispano, junto con un listado que relaciona cada imagen con su fecha.
La url original es la del repositorio de su creador:
* https://tira.danigm.net/

Estructura
tiras-linux-hispano/
├── images/
│   ├── 0607.png
│   ├── 1deMayo.png
│   ├── 2fa.png
│   ├── 3d.png
│   └── ...
│
└── tiras.txt

### Contenido

Directorio **images/**

Contiene copias las imágenes de las tiras.

Archivo **tiras.txt**

Contiene el nombre de cada imagen y su fecha asociada.

El formato es:

imagen.png|YYYY-MM-DD


Por ejemplo:

0607.png|2022-09-25
1deMayo.png|2022-09-25
20years.png|2024-12-23


Este repositorio se utiliza como archivo de las imágenes para facilitar su consulta y visualización mediante scripts sin sobrecargar la web del creador con peticiones.
