## La Tira de Linux Hispano

Repositorio que contiene una copia de las imágenes de La Tira de Linux Hispano. Los nombres de los archivos están compuestos por el nombre y la fecha de publicación. Por ejemplo: `Eof|08-09-2026.png`.

De ese nombre se extrae la primera parte para tener el nombre original y la fecha de publicación para mostrarla con el comando `feh`

La url original es la del repositorio de su creador:
* https://tira.danigm.net/

### Contenido

Directorio **images/**

Contiene copias las imágenes de las tiras.

Este repositorio se utiliza como archivo de las imágenes para facilitar su consulta y visualización mediante scripts sin sobrecargar la web del creador con peticiones.
